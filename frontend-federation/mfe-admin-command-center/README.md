# mfe-admin-command-center

Module federation untuk panel Admin, diakses lewat URL terpisah (`/admin/*`)
dan tidak ditautkan dari portal mahasiswa. Saat ini di-serve oleh
`../app-shell`; seluruh halaman di `app-shell/src/pages/admin` dan
`app-shell/src/pages/AdminLanding.tsx` adalah milik modul ini.
